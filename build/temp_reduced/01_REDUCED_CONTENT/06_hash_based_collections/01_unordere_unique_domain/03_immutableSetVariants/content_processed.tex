\subsection{Immutable Set Variants}

\texttt{frozenset} wraps the same hash-table engine with insertion and deletion disabled at the API level, allowing \texttt{\_\_hash\_\_} to be defined when all elements are hashable.

\subsubsection{\texttt{frozenset} as an Immutable Hashable Set-Like Object}

Construction from an iterable deduplicates members. Mutation methods are absent; non-mutating set algebra (\texttt{union}, \texttt{intersection}, etc.) remains available. Hash is computed from the frozenset contents and stays valid because membership cannot change.

\subsubsection{Using \texttt{frozenset} as a Dictionary Key or Set Element}

Because \texttt{frozenset} is hashable (when its elements are), it may serve as a dict key or as an element of another set---use cases that reject mutable \texttt{set} objects whose \texttt{\_\_hash\_\_} is \texttt{None}.
