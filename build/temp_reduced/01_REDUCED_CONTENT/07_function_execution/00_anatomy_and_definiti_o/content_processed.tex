\section{Anatomy and Definition of Functions}

In Python, a function is a runtime object with metadata, defaults, and a compiled code object. Executing \texttt{def} constructs that object and binds a name; calling it later allocates a frame and runs bytecode. Parameter binding, scope resolution, closures, decorators, generators, and coroutines all depend on this foundation: function objects, call frames, local names, returned references, and frame termination.
