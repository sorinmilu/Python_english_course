\subsection{Variadic Keyword Parameters}

A variadic keyword parameter (\texttt{**kwargs}) collects unbound keyword arguments into a heap-allocated \texttt{dict}. Combined with \texttt{*args}, it completes the flexible signature pattern that disables Vectorcall fast paths when overflow containers must be materialized.

\subsubsection{Argument Packing Mechanics: Collecting Keyword Overflow into \texttt{**kwargs}}

\begin{verbatim}
def show_report(title, **options):
    print(f"title={title!r}, options={options}")

show_report("Annual", year=2026, draft=True)
\end{verbatim}

Possible output:

\begin{verbatim}
title='Annual', options={'year': 2026, 'draft': True}
\end{verbatim}

Each call with keyword overflow allocates a new dict. Keys are parameter names; values are the argument object references.

\subsubsection{Argument Unpacking Operations: Expanding Mappings Across Function Call Boundaries with \texttt{**}}

Call-site \texttt{**mapping} expands a mapping into keyword arguments. Keys must be strings; duplicate binding raises \texttt{TypeError} before the body runs.

\begin{verbatim}
def connect(host, port, timeout=30):
    return f"{host}:{port} timeout={timeout}"

params = {"host": "localhost", "port": 8080}
print(connect(**params))
\end{verbatim}

Possible output:

\begin{verbatim}
localhost:8080 timeout=30
\end{verbatim}

\subsubsection{Key-Value Parameter Extraction, Mapping Lookups, and Safe Override Patterns}

Extract known keys with \texttt{kwargs.pop("key", default)} before forwarding \texttt{**kwargs} to another function. Never mutate a caller-supplied dict in place unless documented; \texttt{**kwargs} is a new dict owned by the callee frame.

When forwarding to callees that support Vectorcall, prefer passing explicit positional/keyword arguments over re-wrapping through \texttt{*args, **kwargs} if the signature is known statically.
